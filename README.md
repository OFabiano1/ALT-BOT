# ALT

> **The Discord bot behind Axolotl BR.**

ALT is the custom Discord bot built for **Axolotl BR**.

It handles the server's systems, automation, moderation and community features — while staying simple enough to keep building and experimenting with.

### What it does

* Moderation
* Automation
* Community systems
* Utility commands
* Server management
* Custom features

### Built with

* Python
* Discord.py
* SQLite

### Development

ALT is built and maintained as part of the Axolotl BR ecosystem.

**Player to Player.**
